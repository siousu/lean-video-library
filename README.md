# Lean Farming Videothek

A fast, searchable gallery of the ~10,900 lean / continuous-improvement videos collected on
[thomasriner.com/lean-farming-innovation](https://thomasriner.com/lean-farming-innovation/):
thumbnails, ⌘K search, author and category filters, light/dark mode and an in-page video player.
A single static page, no build step.

**Live demo:** https://lean-farming-videothek.vercel.app


Everything is in `index.html` plus the video list in `data.json`; host the folder on any static host.

Video list and content: [thomasriner.com/lean-farming-innovation](https://thomasriner.com/lean-farming-innovation/) and the respective video owners. Code: [MIT](LICENSE).
